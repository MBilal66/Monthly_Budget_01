Monthly Expense Tracker — GitHub-ready PWA

Upload these files to the root of a GitHub repository:
index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, README.txt.

GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.
Open the HTTPS Pages URL and use Install app/Add to Home screen on Android when offered.

The original Expense Tracker functionality is preserved. Data uses LocalStorage.
The original SheetJS Excel export and Claude-specific download/AI hooks are also preserved;
those Claude-specific functions may not work outside their supported Claude view.
